# からくり極刑ショー (Karakuri Kyokei Show)

Pyxel製のブラックコメディ装置パズル。架空の極悪人を、ピタゴラ装置で「より苦しく」処刑するほど高得点。

## 起動
```
pip install pyxel
python karakuri_kyokei.py
```

## 操作
- 左クリック: パーツ配置 / 撤去（右クリックでも撤去）
- SPACE または START: 実行（鉄球3発）
- R: 編集に戻る

## パーツ
| パーツ | 効果 |
|---|---|
| BLOCK | 壁・床。鉄球を跳ね返す |
| SPRING | 乗った鉄球を斜め上に跳ばす |
| DOMINO | 倒れて隣へ連鎖。悪人に当たるとダメージ |
| TARAI | 触れると落下。脳天直撃で大ダメージ |
| TICKLE | 起動すると隣接する悪人を生殺しにくすぐる |

## スコア
- 被弾ポイント（連続ヒットでコンボ倍率）
- 悶絶ボーナス（苦しんでいた時間）
- 因果応報: 罪状に合った刑（ステージ1はタライ）で2倍
- 時間内に処刑できないと恩赦扱いで0.3倍
